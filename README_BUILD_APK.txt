JUDICIARY EXPLORER — ANDROID APK PROJECT

WHAT THIS PROJECT DOES
- Installs as “Judiciary Explorer”
- Appears in the Android app drawer/home screen
- Works offline
- Contains the full Judiciary Explorer Pro HTML learning app
- APK can be shared with other Android users

BUILD THE APK IN ANDROID STUDIO
1. Install Android Studio on a Windows, macOS, or Linux computer.
2. Extract JudiciaryExplorerAndroid.zip.
3. Open Android Studio.
4. Choose Open and select the extracted JudiciaryExplorerAndroid folder.
5. Let Gradle sync and install any requested Android SDK components.
6. Choose Build > Build App Bundle(s) / APK(s) > Build APK(s).
7. When Android Studio says APK generated successfully, click Locate.
8. The debug APK is normally:
   app/build/outputs/apk/debug/app-debug.apk
9. Send that APK to an Android phone.
10. Open the APK and allow “Install unknown apps” for the app used to open it, if Android asks.
11. Install. Judiciary Explorer will appear like a normal app.

FOR PUBLIC/PROFESSIONAL SHARING
Use Build > Generate Signed App Bundle or APK > APK and create a signing key.
Keep the signing key safe; future updates should use the same key.

NOTE
Android may warn users about APKs installed outside Google Play. That is normal for directly shared APK files.
